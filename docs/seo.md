# SEO Rules

Every page must have professional metadata.

## Required Metadata

- dynamic title
- description
- canonical path when applicable
- Open Graph title and description
- meaningful robots behavior

## Title Format

Use:

```txt
Page Name | Pluto Booking
```

## Rules

- Metadata should match the page purpose.
- Do not use generic titles like `Home` or `Dashboard`.
- Pages with dynamic resources should generate title and description from the resource data.
- Error and empty states still need useful titles and actions.
