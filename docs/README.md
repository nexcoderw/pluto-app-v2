# PLUTO Customer Frontend Docs

These docs guide frontend implementation for the customer-facing PLUTO app.

## Docs

- `api-endpoints.md` defines backend endpoint file organization.
- `component-structure.md` defines component folders and ownership.
- `design-system.md` defines premium visual rules.
- `styling.md` defines CSS, Tailwind, module CSS, and tab indentation rules.
- `feedback-and-states.md` defines toast, modal, inline errors, and UI states.
- `listing-categories.md` defines multi-category listing behavior and review rules.
- `payment-readiness.md` defines authoritative quote, hold, payment, refund, and financial-state ownership.
- `seo.md` defines page metadata and dynamic title rules.
- `git.md` defines project-labeled commit command output.
